# 云数据库说明

签到系统使用 uniCloud 支付宝云数据库。应用的集合结构、索引和初始化数据位于 `uniCloud-alipay/database`，云函数入口为 `valencia-checkin`。

## 初始化与更新

1. 在 HBuilderX 将 `uniCloud-alipay` 关联到目标支付宝云服务空间。当前项目已关联 `u1`。
2. 首次部署到空空间时，在 `database` 上执行「初始化云数据库」。`*.schema.json` 定义集合结构和权限，`*.index.json` 定义索引，`vu_majors.init_data.json` 提供 12 条专业种子数据。 [DCloud 数据库初始化说明](https://doc.dcloud.net.cn/uniCloud/hellodb.html#init-db)
3. 在 uniCloud 控制台核对 13 个 `vu_` 集合和专业数据。在已有数据的空间只更新本次变更涉及的资源。 [uniCloud 接入与部署](UNICLOUD_DEPLOY.md)

## 集合

| 集合 | 用途 |
| --- | --- |
| `vu_majors` | 专业代码、名称和排序 |
| `vu_accounts` | 账号资料、密码盐与摘要、凭据版本 |
| `vu_student_ids` | 学号到账号的唯一映射 |
| `vu_sessions` | 访问令牌、刷新令牌的摘要及过期时间 |
| `vu_captcha` | 验证码挑战和一次性验证票据 |
| `vu_captcha_rates` | 生成验证码的请求频率统计 |
| `vu_classes` | 班级资料、创建者和邀请码有效期 |
| `vu_invites` | 邀请码到班级的映射 |
| `vu_members` | 班级成员角色、当前状态及历次在班区间 |
| `vu_events` | 活动时间、签到设置及动态码密钥 |
| `vu_records` | 按活动与学生保存签到状态、失败次数及补签历史 |
| `vu_appeals` | 补签申请、审批结果和查询所需的关联标识 |
| `vu_audit` | 班级、活动、补签和账号管理操作的审计日志 |

## 权限与写入

13 个集合的客户端读取、新增、更新和删除权限均关闭。应用通过云函数处理数据。云函数校验登录会话、班级角色、参与资格或数据归属，再执行相应操作。专业字典供服务端核对注册和资料，客户端专业选项由 `utils/constants.js` 提供。

- 注册时，云函数用入学年份、专业代码和随机数字生成 12 位学号，在同一事务中保存账号、学号映射和会话。修改资料不会改写学号。密码以随机加盐的 `scrypt` 摘要保存。
- 动态签到码以活动密钥和 30 秒时间片派生。学生提交 `SHA-256(活动标识|用户标识|六位码)`，服务端匹配当前轮或上一轮，并在签到记录中保留验证摘要和结果。
- 每场活动按名单判定时间与成员在班区间计算应签到人员。创建者不计入。尚未写入 `vu_records` 的应签成员会在详情和统计中显示为未签到。
- 补签审批与记录更新在同一事务中处理。批准后记为已签到，方式为补签。在班级出勤中，补签计入出勤率。
- 退出或移除成员会结束其在班区间。单场历史记录按该场名单判定，当前班级出勤汇总列出仍在班的普通成员。
- 删除班级时，云函数先关闭访问并移除邀请码，然后清理成员、活动、签到记录和补签申请。注销账号会清理该用户的账号、学号映射、所建班级及相关数据。审计日志保留操作记录。

测试数据库权限时使用客户端调用，并在控制台单独核对数据结果。 [发布验收与测试清单](PRODUCTION_TEST_CHECKLIST.md)
