# 发布验收与测试清单

适用于 uniCloud 支付宝云版。部署步骤见 [uniCloud 接入与部署](UNICLOUD_DEPLOY.md)，网页构建与跨域配置见 [H5 部署说明](H5_DEPLOY.md)。每次验收记录版本、服务空间、平台、账号角色、实际结果与对应日志。

## 1. 环境与样本

- [ ] 记录这次测试关联的支付宝云服务空间。当前项目的关联为 `u1`（`env-00jy729wygaj`）。需要清理或并发写入的用例使用可丢弃的测试数据。
- [ ] 准备班级创建者、普通成员和班外账号。另建一个班级供交叉权限检查。
- [ ] 准备立即开始、指定时间、已结束、突击和位置校验活动。按需增加设备绑定和三种签到方式的活动。
- [ ] 准备桌面浏览器、手机浏览器和 Android 真机。正式包验收使用签名 APK。第二台设备用于验证会话和并发。

## 2. 构建、部署与联网

- [ ] HBuilderX 关联正确的空间，测试运行时连接云端云函数。编译输出中的空间标识与目标一致。
- [ ] 控制台可见 13 个 `vu_` 集合、相应索引、`vu_majors` 中的 12 条专业，以及 `valencia-checkin` 云函数。
- [ ] `get_server_time` 返回 UTC 时间和毫秒时间戳，客户端登录页能加载图片验证码。
- [ ] H5 发行目录为 `unpackage/dist/build/web`，网站在 `/valencia/check-in/` 访问。入口、脚本、样式和版本文件均可访问，缺失资源返回 404。
- [ ] 正式网页的自定义域名或外部站点域名已配置到目标空间的「Web 安全域名」。通过实际 HTTPS 地址验证云函数调用。 [DCloud 跨域说明](https://doc.dcloud.net.cn/uniCloud/hosting.html)
- [ ] `APP_VERSION` 和 `static/version.json` 中的版本值一致。入口和版本文件按托管策略校验缓存，浏览器能切换到新版本。
- [ ] Android 发行使用有效的 DCloud 应用标识、包名和签名。名称、图标、启动页、权限说明、`versionName` 和 `versionCode` 符合本次发行要求。
- [ ] Android 正式包包含 `Barcode` 和 `Geolocation`，安装后启动、扫码和定位权限正常。

## 3. 账号、图片验证码与会话

- [ ] H5 和 Android 均先完成注册验证码，再填写资料。注册成功显示 12 位学号，复制、再次输入学号及勾选确认后可进入首页。
- [ ] 校验姓名、注册年份、专业、12 位学号及密码格式。覆盖空值、长度边界、控制字符，以及密码缺少字母、数字或包含空白。
- [ ] 用新学号和密码登录成功。错误密码或未注册学号均提示“学号或密码错误”。
- [ ] 验证码输入错误、使用过期图片或重复验证同一挑战时，页面提示重新加载。通过后票据只能用于对应操作，过期或重复使用应失败。
- [ ] 在测试端确认验证码生成请求达限后有明确提示，时间窗口结束后可以重新加载。
- [ ] 关闭并重新打开网页或应用后，可以恢复仍有效的会话。访问令牌将到期时会刷新，刷新令牌失效时需要重新登录。
- [ ] 刷新后旧访问令牌和旧刷新令牌均失效。刷新令牌不能用于普通业务调用。
- [ ] 联网退出后清理本地会话，旧会话不能继续调用业务接口。登录和云函数日志中没有明文密码、完整令牌或验证码答案。

## 4. 个人资料与注销

- [ ] 修改姓名、入学年份和专业后，个人主页及重新打开后的资料一致。学号保持原值。
- [ ] H5 修改资料和密码时要求对应图片验证码。Android 按页面流程直接提交，并由服务端校验权限。
- [ ] 旧密码错误、两次新密码不一致或新旧密码相同时不能修改。成功后旧密码不能登录，新密码可登录。当前会话仍可用，其他设备的旧会话失效。
- [ ] 可丢弃账号必须输入完整学号和“注销账号”，勾选确认并通过最终弹窗。注销后账号、学号映射、所建班级及相关数据按设计清理，其他账号数据保持完整。 [账号与数据清理说明](M2_AUTH.md)

## 5. 班级与活动发布

- [ ] 创建者建班得到 8 位邀请码，页面的四档有效期与保存值一致。验证正确、错误、过期和重复加入的情形。
- [ ] 创建者可以看到名单和邀请码，普通成员只看到权限内的基本信息。班外账号无法查看班级详情或管理成员。
- [ ] 普通成员可退出，创建者可移除普通成员。核对未来活动的参与资格与历史单场记录，创建者仍可查看已有历史结果。
- [ ] 从发布起支持 1 至 10080 分钟。成功后进入正在签到的详情，创建者不计入应签人数。
- [ ] 指定时间发布覆盖设备时区、跨日及夏令时切换。测试开始时刻早于服务器时间 5 分钟的边界和刚好 7 天的活动。核对 UTC 存储时刻、页面本地时间和活动状态。无效时区、不完整日期、结束不晚于开始或时长超过 7 天应被拒绝。
- [ ] 仅数字、仅二维码、两种皆可三类活动的选项生效。突击活动在开始前对参与者隐藏。
- [ ] 开启 1 公里位置校验时须提供发布者定位。设备绑定显示确认提示，取消后保持关闭。
- [ ] 创建者可删除未开始活动、提前结束进行中活动。普通成员和班外账号不能管理其他人的活动。

## 6. 首页、动态码与签到结果

- [ ] 首页进入时取得三组活动，切换页签及已结束筛选时复用缓存。下拉刷新重新取数，刷新失败有提示，切换账号后显示对应数据。
- [ ] 详情可看到准确的活动状态、应签名单或本人状态。创建者刷新详情后，人数与结果页相符。
- [ ] 开始前 5 分钟内创建者可取得码，较早和结束后不可用。二维码与六位码一致。倒计时归零后按「刷新签到码」或下拉可取得新码。
- [ ] 输入或粘贴六位数字会自动提交。合法二维码扫码后自动提交。非六位数字内容会给出错误提示。
- [ ] 当前轮签到成功。上一轮仍可提交且标记“上一轮码”。更早且未与当前或上一轮重复的码应失败。
- [ ] 同一学生在同一轮输错 5 次后，即使改用正确码也须等到下一轮。已经签到的学生重复提交仍只有一条记录。
- [ ] 未开始、已结束或缺少参与资格时拒绝签到。创建者和普通成员的签到入口符合角色。
- [ ] 有位置要求时测试范围内、1 公里边界、超出范围、缺少定位、拒绝授权及关闭系统定位。无位置要求的活动可在未授权定位时签到。
- [ ] 有设备要求时核对首次成功写入的设备标识。使用第二台设备重复提交不能覆盖已签到记录。核对缺少设备标识的验证提示。
- [ ] 活动开始后，创建者可手动调整成员状态。已签到、补签、未签到三项应与应签总数一致。

## 7. 补签、出勤与导出

- [ ] 活动结束且本人漏签时才能申请补签。理由范围为 10 至 500 字，H5 需要补签用途的验证码。
- [ ] 待审批不能重复申请，可以撤回。撤回后重新申请不额外消耗机会。每名学生在同一活动最多保留 3 次未撤回申请。
- [ ] 审批权限仅限活动创建者。批准后改为已签到、方式为补签。拒绝会保留当前签到状态，理由和审批备注正确显示。已有结果的申请不能重复审批。
- [ ] 学生的申请列表、创建者的收到列表和待审批计数一致。班外账号无法查看双方的补签详情。
- [ ] 班级出勤只汇总已结束活动及仍在班的普通成员，应签、正常签到、补签、未签到和出勤率与成员明细吻合。补签计入出勤率。
- [ ] H5 成功下载 CSV，Android 可将 CSV 复制并粘贴到表格软件。检查中文、逗号、引号、换行、空值和文件名。
- [ ] 中文表格软件以文本列导入学号。以 `=`、`+`、`-`、`@` 开头的文本字段在 CSV 中带有防止公式求值的前缀。

## 8. 客户端权限与接口验证

### 集合权限

- [ ] 控制台核对 13 个集合的 `permission`，读取、新增、更新和删除均为 `false`。
- [ ] 在测试客户端调用 `uniCloud.database()`，检查匿名和应用已登录状态都无法直接读取业务集合。使用测试文档检查直接新增、更新和删除均被拒绝。
- [ ] 使用控制台只读核对测试数据存在及写入前后未被改动。控制台的管理员查询与客户端权限检查分别记录。 [DCloud 客户端数据库与权限说明](https://doc.dcloud.net.cn/uniCloud/clientdb)

### 云函数权限

- [ ] 未登录调用 `get_home_checkins`、`get_checkin_event` 或 `submit_checkin`，返回 `UNAUTHORIZED`。`get_server_time` 可以匿名调用。
- [ ] 注册和登录需要各自用途的有效验证码票据。已登录的 H5 操作使用缺少、过期、重复使用、用途错误或其他账号的票据时应失败。
- [ ] 普通成员能读取自己有资格参加的活动，但无法读取创建者专用签到码、出勤汇总或管理结果。
- [ ] 用班外账号请求测试班级、活动、补签或结果，不能取得权限外的数据。学生不能为其他成员提交补签，且不能审批别人的申请。
- [ ] 业务调用返回字段中不包含账号密码摘要、会话摘要、活动密钥或验证码答案。错误响应不包含内部错误栈。
- [ ] 核对排序、筛选、签到方式、时区、坐标和标识的异常输入。用户填写的姓名、标题和理由按文本显示。

在已关联测试空间的 uni-app 客户端中，从调试入口调用 `verifyCloudAccess()`，核对公开方法与需登录方法的返回。

```js
async function verifyCloudAccess() {
  const call = method => uniCloud.callFunction({
    name: 'valencia-checkin',
    data: { method, params: {}, accessToken: null }
  })

  const { result: clock } = await call('get_server_time')
  const { result: home } = await call('get_home_checkins')

  if (!clock?.ok || clock.data.timezone !== 'UTC' || !Number.isFinite(clock.data.epoch_ms)) {
    throw new Error('服务器时间返回异常')
  }
  if (home?.ok !== false || home.code !== 'UNAUTHORIZED') {
    throw new Error('首页未按预期拒绝未登录请求')
  }
}
```

## 9. 平台、并发与发布确认

- [ ] H5 检查窄屏、桌面布局、刷新、历史导航和相机定位权限。支持 `BarcodeDetector` 的浏览器可扫码，允许数字签到的活动可手输。
- [ ] Android 检查冷启动、后台恢复、断网恢复、扫码取消、相机和定位拒绝、系统字体放大及底部安全区。真机实际获取定位，并能导出 CSV 文本。
- [ ] 两设备同时为同一账号提交同一场签到，最终仅保留一条成功记录。并发加入同一班级不会出现重复成员。
- [ ] 并发批准同一补签或批准与撤回同时进行时，最终申请和签到状态一致。
- [ ] 使用测试班级检查删除时对邀请码、成员、活动、记录和补签的清理。覆盖删除与加入同时发生的情况。若断网或超时，先核对服务端结果，再验证重试行为。
- [ ] 核对大班名单、统计与导出速度，记录测试人数、耗时和错误。详情页离开、恢复或刷新时计时器行为正常。
- [ ] 发布前在实际 H5 域名和签名版 Android 上复核完整流程。归档测试记录、待处理问题和数据恢复办法。
