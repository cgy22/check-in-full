# 🎓 瓦莱希雅大学签到系统

本项目为虚构的瓦莱希雅大学提供班级签到功能。前端使用 uni-app（Vue 3），支持 H5 和 Android，后端使用 uniCloud 支付宝云。班级创建者可以发布签到、查看出勤统计和审批补签，学生可以用学号登录并签到。

## 快速开始

1. 使用支持 Vue 3 和 uniCloud 的 HBuilderX 导入项目目录，并登录有权访问目标服务空间的 DCloud 账号。
2. 右键项目中的 `uniCloud-alipay`，查看「关联云服务空间」。现有项目已关联支付宝云服务空间 `u1`，空间标识为 `env-00jy729wygaj`。
3. 用现有 `u1` 调试时，可以直接使用已部署的数据库和 `valencia-checkin` 云函数。切换到新的服务空间时，先完成下文的云端部署。
4. 在 HBuilderX 中选择「运行到浏览器」调试 H5，或连接 Android 设备后选择「运行到手机或模拟器」。在运行控制台选择连接云端云函数。H5 本地调试使用 HBuilderX 给出的 `localhost` 地址。 [DCloud 运行与调试说明](https://doc.dcloud.net.cn/uniCloud/rundebug.html)

首次使用时注册一个班级创建者账号和一个学生账号。创建者建班并分享邀请码。学生加入班级后，创建者发布签到并显示动态码，学生提交签到。活动结束后可以查看出勤结果，漏签学生也可以提交补签申请。

## 云端部署

### 初始化数据库与上传云函数

1. 在 HBuilderX 将 `uniCloud-alipay` 关联到目标支付宝云服务空间。
2. 首次部署到空空间时，右键 `uniCloud-alipay/database`，选择「初始化云数据库」。初始化会创建 13 个以 `vu_` 开头的集合，上传集合结构和索引，并在 `vu_majors` 导入 12 个专业。已有业务数据的空间按需上传变更的集合结构和索引。 [DCloud 数据库初始化说明](https://doc.dcloud.net.cn/uniCloud/hellodb.html#init-db)
3. 右键 `uniCloud-alipay/cloudfunctions/valencia-checkin`，上传云函数。登录、班级、签到、补签和图片验证码共用这个云函数。
4. 重新运行客户端，打开登录页并点击「加载验证码」。能显示图片后，再用测试账号核对注册、建班、入班、签到和补签。

### H5 发行与托管

1. 在 HBuilderX 的「发行」菜单选择网站发行，产物位于 `unpackage/dist/build/web`。 [DCloud 网站发行说明](https://uniapp.dcloud.net.cn/quickstart-hx)
2. 将产物完整部署到网站的 `/valencia/check-in/` 路径，保留 `index.html`、`assets/` 和 `static/` 等文件。改用其他路径时，同步修改 `manifest.json` 的 `h5.publicPath` 和 `h5.router.base` 后重新构建。当前路由采用 `hash` 模式。
3. 使用自定义域名或其他网站托管时，在目标服务空间的「跨域配置」中将实际前端域名加入「Web 安全域名」。使用非默认端口时一并填写端口。uniCloud 前端网页托管的默认域名和本地 `localhost` 可用于测试。 [DCloud 前端网页托管与跨域说明](https://doc.dcloud.net.cn/uniCloud/hosting.html)
4. 发布后通过实际站点地址打开登录页并加载验证码，确认静态资源和云函数调用均正常。

发版前将 `utils/config.js` 中的 `APP_VERSION` 与 `static/version.json` 中的 `version` 更新为同一个新值，供网页版本提示使用。

### Android 打包

1. `manifest.json` 中当前的 DCloud 应用标识为 `__UNI__4ED33A5`。打包账号需要有该应用的项目权限。
2. 确认应用模块中启用了 `Barcode`（扫码）和 `Geolocation`（定位）。正式发行时，核对应用包名、版本号和签名配置。
3. 在 HBuilderX 选择「发行」中的原生应用云端打包，选择 Android，生成 APK 后在真机验证登录、扫码和定位权限。 [DCloud 原生应用打包说明](https://uniapp.dcloud.net.cn/quickstart-hx)

如需给此前使用 `__UNI__565F905` 发布的 Android 应用提供覆盖更新，需要取得原 DCloud 应用标识的项目成员权限，并沿用原 Android 包名和签名。

### 旧数据

旧版 Supabase 的账号、班级和签到记录尚未迁移。当前服务空间可以注册新账号。旧账号的登录凭据和业务记录需要另行迁移。 [uniCloud 接入与部署](docs/UNICLOUD_DEPLOY.md)

## 功能

- 注册时填写姓名、入学年份、专业和密码，系统生成 12 位学号，由 4 位入学年份、2 位专业代码和 6 位随机数字组成。支持登录、会话恢复、修改资料和密码、退出及注销账号。登录需要学号和密码，请保存好学号。项目暂未提供邮箱找回密码。
- 班级创建者可以建班、查看成员、移除成员及删除班级。学生凭 8 位邀请码入班，也可以退出。邀请码有效期可选 1 小时、24 小时、7 天或 30 天。
- 创建者可以为自己的班级发起签到，选择发布后立即开始或指定当地日期、时间与时区。签到最长持续 7 天。支持六位数字、二维码或两者并用，以及突击签到、1 公里位置校验和设备绑定。创建者可以删除未开始的活动或提前结束进行中的活动。班级创建者不计入签到统计。
- 动态签到码每 30 秒轮换，二维码包含同一组六位数字。系统接受当前轮和上一轮码，并标记使用上一轮码的记录。每位参与者在同一轮内最多可输错 5 次，输满六位自动提交。Android 使用原生扫码，H5 扫码依赖浏览器的 `BarcodeDetector` 支持。活动允许数字签到时，也可以直接输入六位码。
- 签到结束后，漏签学生可以填写 10 至 500 字的理由提交补签。待审批申请可以撤回，每名学生在同一场活动中最多保留 3 次未撤回的申请。创建者可以批准或拒绝并填写备注。批准的补签计入出勤。
- 创建者可以查看单场签到结果、班级出勤统计和成员签到明细。网页端可以下载逗号分隔文件（CSV），Android 将文件内容复制到剪贴板。
- 首页按进行中、未开始和已结束显示活动，切换筛选时复用缓存。下拉可以重新请求数据，签到详情以服务端返回的最新结果为准。

## 人机验证

| 平台 | 注册 | 登录 | 建班、加入班级、发布签到、修改资料或密码、申请补签 |
| --- | --- | --- | --- |
| H5 | 先验证，再填写表单 | 图片验证码 | 图片验证码 |
| Android | 先验证，再填写表单 | 图片验证码 | 直接操作 |

图片验证码由云函数生成。验证成功后获得一张五分钟内有效、限用一次的票据。票据绑定操作用途，已登录操作的票据也绑定当前账号。各端提交业务操作时，云函数都会校验会话、相关角色和数据权限。

## 技术与目录

H5 和 Android 都通过 `uniCloud.callFunction` 调用 `valencia-checkin`。云函数在支付宝云的 Node.js 环境中运行，并读写云数据库。集合权限禁止客户端直接读写。账号密码以加盐后的 `scrypt` 摘要保存，登录会话由云函数签发和校验。

签到活动的状态和动态码以服务器时间为准。指定时间发布时，云函数将所选时区的日期和时间换算为 UTC 保存，页面按设备当地时区显示。签到时客户端提交由活动标识、用户标识和六位码生成的 `SHA-256` 摘要。位置校验以发布者的设备位置为圆心，半径为 1 公里。

| 路径 | 用途 |
| --- | --- |
| `pages/` | 登录、首页、班级、签到、补签和个人资料页面 |
| `components/`、`composables/` | 公共组件与会话状态 |
| `utils/authApi.js` | 云函数调用入口 |
| `uniCloud-alipay/cloudfunctions/valencia-checkin/` | 登录、班级、签到、补签、权限管理和图片验证码 |
| `uniCloud-alipay/database/` | 云数据库集合结构、索引和专业字典 |
| `manifest.json`、`pages.json` | 应用、平台、页面和路由配置 |
| `static/` | 图标、启动图和网页版本文件 |
